# Dao Duc Manh - Professional Portfolio 🚀

A vibrant, interactive, and high-performance personal portfolio website built for **Dao Duc Manh**, specializing in **International Business**, **Supply Chain Operations**, **SAP ERP & WMS**, and **Customer Service Logistics**.

---

## 🌟 Highlights & Features

1. **Vibrant Visual Aesthetic:**
   - Deep cyber-space slate canvas with glowing ambient light meshes.
   - Glassmorphism design system (`backdrop-filter: blur`, neon borders, subtle depth shadows).
   - Dynamic 3-theme color switcher: **Neon Cyber** (default), **Emerald Trade Network**, and **Sunset Radiant**.

2. **Interactive Elements:**
   - **Interactive Trade-Route Background Canvas:** Constellation of shipping lines & data nodes responding to cursor movements.
   - **Dynamic Role Typewriter:** Highlighting core operational strengths automatically.
   - **Interactive 3D Profile Card:** Tilt and parallax reflection responding to mouse positioning.
   - **Live End-to-End Logistics Pipeline:** 5-stage interactive workflow (Order Intake ➔ WMS/SAP Sync ➔ Trade Docs & B/L ➔ Dispatch ➔ Customer Resolution) with real-time terminal simulation.
   - **Interactive Skill Matrix:** Filter cards by *Systems & Tech*, *Import/Export & Trade*, *Customer Care*, and *Data & Excel*.
   - **Live Logistics & Excel Simulation Playground:** Simulate real-time shipments with port routings, status lookups, and automated actions.
   - **One-Click Actions:** Instant email trigger, phone copying, and contact form dispatch.

## 🚀 How to View Locally

Simply open `index.html` in any modern web browser:

1. Open File Explorer to:
   ```
   C:\Users\MANH\.gemini\antigravity\scratch\manh-portfolio
   ```
2. Double-click **`index.html`** to launch it in Chrome, Edge, or Firefox.

Or run a local development server using PowerShell:
```powershell
# Using Python:
python -m http.server 8000
# Then open http://localhost:8000 in your browser!

# Or using npx serve:
npx serve .
```

## 🌐 Free 1-Click Deployment Options

### Option 1: GitHub Pages
1. Create a repository named `portfolio` on GitHub.
2. Push this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings > Pages**, set branch to `main`, and save. Your site is live!

### Option 2: Netlify or Vercel
- Simply drag-and-drop the `manh-portfolio` folder onto [Netlify Drop](https://app.netlify.com/drop) or link via Vercel for instant free global HTTPS hosting.
